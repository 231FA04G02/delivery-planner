Algorithm

A* Search finds the shortest road path between every pair of stops using a straight-line distance heuristic.

Nearest-Neighbour greedily builds the initial visit order respecting capacity and priority.

2-opt improves the sequence by reversing sub-tours until no gain is possible.

🔍 Compare Algorithms

A* – informed, uses heuristic, fewest nodes explored

BFS – uninformed, finds fewest hops

Dijkstra – uninformed, optimal cost, no heuristic

How It Works

A two-stage AI pipeline — graph search for shortest paths, planning agent for delivery sequencing.

🗺️
Custom City Graph

You define every node (location with X,Y coordinates) and edge (road with distance). The system builds a NetworkX weighted graph from your input.

⭐
A* Informed Search

A* uses h(n) = Euclidean distance to goal as a heuristic, expanding fewer states than BFS or Dijkstra while still returning the optimal path.

🤖
Planning Agent

Nearest-neighbour builds an initial route respecting capacity and priority. 2-opt local search then improves it by reversing sub-sequences.
